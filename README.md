# File Organizer

Простой скрипт на Python, который автоматически раскладывает файлы по папкам на основе их расширения. 

## Что умеет

- Сканирует указанную папку
- Определяет категорию файла по расширению
- Создаёт папки для категорий (если их нет)
- Перемещает файлы в соответствующие папки
- Выводит в консоль отчёт о перемещении

## Категории

| Категория | Расширения |
|---|---|
| Изображения | .jpg, .jpeg, .png, .gif, .webp |
| Документы | .pdf, .doc, .docx, .txt, .xls, .xlsx |
| Видео | .mp4, .avi, .mkv, .mov |
| Музыка | .mp3, .wav, .flac |
| Архивы | .zip, .rar, .7z, .tar, .gz |
| Программы | .exe, .msi, .dmg |
| Всё остальное | попадает в папку «Другое» |

## Стек

- Python 3.10+
- Стандартные библиотеки: `shutil`, `pathlib`
